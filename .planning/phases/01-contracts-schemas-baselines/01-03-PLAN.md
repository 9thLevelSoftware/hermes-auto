Create `src/hermes_auto/gateway/schemas.py` exporting exactly four public names: `SCHEMA_ROOT`, `SchemaLoadError`, `load_schemas`, and `validate`.

```python
SCHEMA_ROOT: pathlib.Path = pathlib.Path(__file__).resolve().parent.parent / "data" / "schema"
```

`class SchemaLoadError(Exception)` — raised for duplicate `$id` values and unparseable files.

`def load_schemas(root: pathlib.Path | None = None) -> dict[str, dict]`:
- Defaults `root` to `SCHEMA_ROOT`.
- If `root` does not exist, return `{}` — do not raise. Plan 01-04's `routing/` directory may not exist when this plan's tests run in parallel.
- Recursively glob `**/*.schema.json`. Use `sorted()` on the glob result so load order is deterministic and error messages are reproducible.
- Parse each file. On `json.JSONDecodeError`, raise `SchemaLoadError` with a message naming the file path and the underlying error.
- Key the result by each schema's `$id`. If a file has no `$id`, raise `SchemaLoadError` naming the file.
- On duplicate `$id`, raise `SchemaLoadError` naming both file paths.
- Return the mapping.

`def validate(instance: object, schema_id: str, schemas: dict[str, dict] | None = None) -> None`:
- Defaults `schemas` to `load_schemas()`.
- Raises `KeyError` with the available ids listed if `schema_id` is absent.
- Calls `jsonschema.validate(instance=instance, schema=schemas[schema_id])`, letting `jsonschema.ValidationError` propagate unchanged so callers see the full error path.
- Returns `None` on success.

Add a module docstring stating that discovery is by recursive glob specifically so new schema directories can be added without editing this module, and add `__all__ = ["SCHEMA_ROOT", "SchemaLoadError", "load_schemas", "validate"]`.

Do not add caching, an LRU decorator, or a module-level singleton. Later phases may need to load from a temp directory in tests, and a cached singleton would break that.

Do not implement request canonicalization, token counting, ingress auth, or routing here. This module loads and validates schemas, nothing more.
