  <files>src/hermes_auto/hermes_shim/installer.py, tests/integration/test_shim_installer.py</files>
  <action>
Model providers are discovered by scanning `$HERMES_HOME/plugins/model-providers/<name>/`. **`pip install` alone never registers this provider** — that is why this installer exists and why `hermes auto setup` (plan 02-07) is load-bearing rather than convenience.

Create `installer.py` exporting `installed_path(hermes_home=None)`, `install(hermes_home=None)`, `uninstall(hermes_home=None)`, and `InstallError`.

- `installed_path` → `<hermes_home>/plugins/model-providers/hermes-auto/__init__.py`
- `install` creates parent directories, substitutes `base_url` and the token env var name into `SHIM_SOURCE`, writes atomically (temp + `os.replace`), returns the path
- Overwrites **only** when the existing file starts with `MARKER`; otherwise `InstallError` naming the path. Never clobber a file this project did not write.
- `uninstall` removes the file and its directory only if the marker matches; returns False if nothing was installed
- `$HERMES_HOME` unset → resolve Hermes's default; if undeterminable, `InstallError` naming the variable

Tests, all against a **temp `HERMES_HOME`** — never the real install:
- `install()` creates the file at the expected path and it parses as Python
- Installing twice is idempotent and the second call overwrites cleanly
- A file without the marker is refused with `InstallError`
- `uninstall()` removes it; a second `uninstall()` returns False
- Substituted `base_url` and token env var appear in the written file
- **Drift test**: the envelope produced by the shim's inline logic is structurally identical to `provider.py`'s — same keys, same `protocol_version`. Extract the shim's class by `exec`-ing `SHIM_SOURCE` with a stub `providers` module injected into `sys.modules`, so no real Hermes import is needed.
- **Registration proof**: if a real Hermes install is present, install into a temp `HERMES_HOME`, invoke Hermes's own discovery, and assert `hermes-auto` appears in the provider list. If Hermes is absent, skip with an explicit reason and record it in the summary — do not silently pass.
