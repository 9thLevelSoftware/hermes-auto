  <action>
One test per surface named in the phase success criteria: **CLI, TUI, gateway, desktop, cron**.

Each asserts only:
1. Hermes resolves the `hermes-auto` provider and can select a virtual model (proving the directory-scan shim registered — the thing `pip install` alone does not do)
2. A conversation completes end to end
3. A tool call fires and its result is returned
