<task type="auto">
  <name>Task 2: The scripted mock upstream</name>
  <files>tests/integration/mock_upstream.py</files>
  <action>
Create `MockUpstream` on stdlib `http.server.ThreadingHTTPServer`. Stdlib is a deliberate choice: this server must emit byte sequences no client library would let you send — a truncated stream, a frame split inside a UTF-8 codepoint, a malformed chunk.

Interface:
- Context manager. Binds `127.0.0.1` port `0`, exposes `.url`.
- `.script(fixture_name)` — the next request replays that fixture's bytes, with the fixture's recorded HTTP status and headers.
- `.set_first_byte_delay(seconds)` — sleeps before the first byte. Plan 02-08's TTFT gate needs this so it measures gateway overhead against a realistic upstream rather than against localhost speed, where the overhead would be invisible.
- `.set_rechunk(sizes)` — replays the same bytes re-split at arbitrary offsets. This is the primitive plan 02-08's `hypothesis` fuzzer drives, and it is what catches relays that break on frames split across TCP reads.
- `.requests` — every received request as `{method, path, headers, body}` with the body JSON-parsed when possible, so tests can assert `_hermes_auto` was stripped before forwarding.
- Writes with `wfile.write(b)` + `wfile.flush()` per chunk. Never buffer the whole body; the mock must be able to stream slowly.
- `midstream_disconnect` closes the connection without a terminating frame.

Do not validate what it receives — it is an oracle, not a gatekeeper. Do not import anything outside stdlib.
