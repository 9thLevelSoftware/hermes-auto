# Research archive

This directory preserves the original research-oriented Hermes Auto Router
design, ADRs, evaluation proposal, and planning history.

The material describes a broader system involving learned capability prediction,
model cards, evaluation, outcome telemetry, adapters, and replay. Those concepts
are historical context only. They are not part of the active `/model auto`
product and should not be used as current implementation documentation.
